ছবি থেকে Base64 কোড (Image to Base64)

ছবি আপলোড না করেই তার Base64 ডেটা URI বানান — CSS ও HTML-এ সরাসরি বসানোর জন্য।

ছবি এখানে ড্র্যাগ করুন
অথবা ক্লিক করে ফাইল বাছুন

কীভাবে ব্যবহার করবেন?

  1. ১. ছবি দিন যে ছবিটি রূপান্তর করতে চান সেটি বাছুন।
  2. ২. কোড কপি করুন ডেটা URI, CSS বা HTML কোড কপি বোতামে চাপ দিন।
  3. ৩. ব্যবহার করুন কোডটি আপনার ওয়েবসাইট বা ইমেইলে বসিয়ে দিন।

সাধারণ জিজ্ঞাসা (FAQ)

Base64 কি ছবির সাইজ কমায়?

না, উল্টে — ডেটা URI সাধারণত আসল ফাইলের ৩৩% বেশি জায়গা নেয়। তাই বড় ছবির জন্য ফাইল পাথাই ভালো।

কখন Base64 ব্যবহার করব?

ছোট আইকন, ইমেইল টেমপ্লেট বা CSS-এ ছোট ছবি বসানোর সময় — ফাইল আলাদা রাখতে হয় না।

ছবি কি আপলোড হয়?

কখনোই না — পুরু ফাইল পড়া আপনার ব্রাউজারেই হয়।

বড় ছবির জন্য কী করব?

ছবির সাইজ কমাতে রিসাইজ বা কম্প্রেস টুল ব্যবহার করুন, তারপর Base64 করুন।

Base64 কোডে কি লাইন ব্রেক থাকে?

না, কোডটি এক লাইনেই থাকে যাতে সরাসরি CSS বা HTML-এ বসানো যায়।

Base64 থেকে আবার ছবি বানানো যাবে?

হ্যাঁ — data URI ব্রাউজারের ঠিকানা বারে সরাসরি ছবি হিসেবে খোলে। যেকোনো Base64 ডিকোডারেও উল্টো করা যায়।
